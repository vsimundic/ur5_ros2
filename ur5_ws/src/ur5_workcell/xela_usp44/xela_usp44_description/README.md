# XELA USP44 description

This package ports the simple `24.6 x 24.6 x 6 mm` box used for the XELA
USP44 tactile sensor in the legacy workcell description. It contains no
sensor driver or ROS interfaces. The workcell mounts it to Finger A's
`AGS_finger-dist002` link using the distal-relative equivalent of the legacy
Basic/open pose, so it follows the articulated fingertip. Dimensions and the
physical mounting transform still require measurement.
